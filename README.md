# Numerical-Pricing-of-Vanilla-and-Barrier-Options
This repository implements pricing models for European and barrier (up-and-out) call options using Cox-Ross-Rubinstein (CRR) binomial trees, Monte Carlo simulations, and closed-form solutions. The project analyzes numerical error convergence rates for tree and simulation approaches, evaluates option Greeks including Delta and Vega, and implements variance reduction techniques such as antithetic variables.

### Project context: 
Assignment for the Financial Engineering course @ Politecnico di Milano
